case study

Hero Academy

A gamified learning platform for gifted, creative, and neurodivergent learners.

PythonFlaskSQLiteJinja2JavaScriptAI coaching

Mastery over completion. AI should guide the learner's thinking, not replace it.

The problem

Many learning apps under-challenge advanced students, reward activity instead of understanding, and, with AI, can hand students the answer before they've had a chance to reason. Hero Academy is built around learner agency, real challenge, and feedback that teaches.

What I built

  • Math Arena with procedural challenges, rule-based difficulty adjustment, and a persisted four-stage hint ladder (Notice → Focus → Strategy → Bridge) that prevents premature answer disclosure.
  • Writing Quest with optional AI-assisted feedback.
  • Atlas Quest: geography pathways, an Explorer Journal, passport stamps, and SVG badges.
  • Persistent progression: XP, achievements, and customization stored in SQLite.
  • Modular Flask APIs for tutoring and quest generation.

Engineering highlights

  • Extracted progression logic and SQLite persistence into dedicated modules, separating business rules from routes and templates.
  • Added CSRF protection during the refactor.
  • Wrote unit and route tests covering progression rules, persistence, answer parsing, request validation, and duplicate-reward prevention, guided by a formal test plan (functional, acceptance, and regression testing).
  • Chose a modular monolith over premature microservices, keeping the app simple while leaving clean seams for growth.

Current status

Active development as a single-learner prototype. Next on the roadmap: authentication and learner accounts, expanded Writing Quest, reusable hints across every experience, and learning analytics that measure mastery rather than screen time.

The source code is private because Hero Academy is planned as a commercial product. I'm happy to walk through the architecture, design decisions, and tests in an interview.
